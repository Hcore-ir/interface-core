# H.CORE (InterFace-[facilities,clients])

**H.CORE** is an open-source, cross-platform Hospital Management System (HMS) mobile frontend built with React Native and Expo. This repository contains the mobile interface for interacting with the H.CORE backend API, offering a modern, modular, and free solution for hospital operations on the go.

## 🚀 Project Overview

- **Framework**: React Native (JavaScript / TypeScript)
- **Toolkit**: Expo (Fast development and testing)
- **Architecture**: Modular, Extensible, API-Driven
- **License**: GPL v2
- **Repository Status**: Open & Free, contributions welcome

## 📋 Features

- Mobile interface for patient registration and management
- Appointment scheduling and reminders
- Access to medical records
- Mobile billing view
- Secure role-based access
- Real-time notifications and status updates
